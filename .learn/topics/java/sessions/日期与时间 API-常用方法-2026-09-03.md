## Positioning

日期与时间 API 的常用方法，是在理解 `LocalDate`、`LocalTime`、`LocalDateTime`、`Period`、`Duration` 这些类型之后，真正开始写业务代码的核心工具箱。

## Analogy

可以把日期时间对象想成一张不可涂改的日历卡片。你不能直接把原卡片上的日期擦掉改成明天；你只能根据它生成一张新的卡片。`plusDays()`、`minusMonths()`、`withDayOfMonth()` 这些方法，都是“基于当前卡片生成另一张卡片”。

## Core Mechanism

`java.time` 的方法大致分成 6 类：

1. 创建日期时间：`now()`、`of()`、`parse()`
2. 获取某个部分：`getYear()`、`getMonthValue()`、`getDayOfMonth()`、`getHour()`
3. 加减时间：`plusDays()`、`plusMonths()`、`minusYears()`、`plus(Period)`
4. 修改某个部分：`withYear()`、`withMonth()`、`withDayOfMonth()`
5. 比较先后：`isBefore()`、`isAfter()`、`isEqual()`
6. 格式化与解析：`format(DateTimeFormatter)`、`parse(text, formatter)`

最常用的是 `LocalDate`。如果业务只关心日期，例如会员卡开卡日、到期日、生日、账单日，就优先使用它。

```java
LocalDate today = LocalDate.now();
LocalDate startDate = LocalDate.of(2026, 9, 3);
LocalDate parsed = LocalDate.parse("2026-09-03");
```

`now()` 表示当前日期；`of()` 是手动指定年月日；`parse()` 是从字符串解析，默认支持 `yyyy-MM-dd` 格式。

获取日期的某一部分：

```java
int year = startDate.getYear();
int month = startDate.getMonthValue();
int day = startDate.getDayOfMonth();
```

日期加减：

```java
LocalDate expireDate = startDate.plusYears(1);
LocalDate nextMonth = startDate.plusMonths(1);
LocalDate yesterday = startDate.minusDays(1);
```

这些方法都不会修改 `startDate`，而是返回一个新的 `LocalDate`。

修改日期的某一部分：

```java
LocalDate firstDay = startDate.withDayOfMonth(1);
LocalDate sameDayNextYear = startDate.withYear(2027);
```

`withXxx` 不是“加减”，而是“替换某个部分”。比如 `2026-09-03.withDayOfMonth(1)` 得到 `2026-09-01`。

比较日期：

```java
LocalDate today = LocalDate.of(2026, 9, 3);
LocalDate expireDate = LocalDate.of(2026, 10, 3);

boolean expired = expireDate.isBefore(today);
boolean active = !expireDate.isBefore(today);
```

这里要注意业务定义：如果到期日是今天，到底算有效还是过期？上面 `!expireDate.isBefore(today)` 表示“到期日是今天也算有效”。

`Period` 用来表达日期跨度：

```java
Period oneMonth = Period.ofMonths(1);
Period threeYears = Period.ofYears(3);

LocalDate expireDate = startDate.plus(oneMonth);
```

两个日期之间也可以算 `Period`：

```java
Period between = Period.between(startDate, expireDate);
int years = between.getYears();
int months = between.getMonths();
int days = between.getDays();
```

`LocalTime` 常用在只关心一天内时间的场景：

```java
LocalTime openTime = LocalTime.of(9, 30);
LocalTime closeTime = LocalTime.of(22, 0);

boolean beforeOpen = LocalTime.now().isBefore(openTime);
```

`LocalDateTime` 是日期加时间：

```java
LocalDateTime createdAt = LocalDateTime.of(2026, 9, 3, 14, 30);
LocalDateTime oneHourLater = createdAt.plusHours(1);
```

如果你只是会员卡到期日，不需要几点几分，就不要用 `LocalDateTime`。用得越精确，业务规则越要解释清楚。

`Duration` 用来表达精确时间间隔：

```java
Duration timeout = Duration.ofSeconds(30);
Duration cacheTtl = Duration.ofMinutes(10);

LocalDateTime deadline = LocalDateTime.now().plus(timeout);
```

它适合接口超时、缓存过期、倒计时、任务耗时，不适合“会员卡一年有效期”这种日历周期。

格式化日期时使用 `DateTimeFormatter`：

```java
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy/MM/dd");

LocalDate date = LocalDate.of(2026, 9, 3);
String text = date.format(formatter); // 2026/09/03

LocalDate parsed = LocalDate.parse("2026/09/03", formatter);
```

## Code Example

```java
import java.time.LocalDate;
import java.time.Period;
import java.time.format.DateTimeFormatter;

enum CardDuration {
    ONE_MONTH("月卡", Period.ofMonths(1)),
    ONE_YEAR("一年卡", Period.ofYears(1)),
    THREE_YEARS("三年卡", Period.ofYears(3)),
    LIFETIME("终身卡", null);

    private final String text;
    private final Period period;

    CardDuration(String text, Period period) {
        this.text = text;
        this.period = period;
    }

    LocalDate expireDateFrom(LocalDate startDate) {
        if (this == LIFETIME) {
            return LocalDate.of(9999, 12, 31);
        }
        return startDate.plus(period);
    }

    String getText() {
        return text;
    }
}

public class DateMethodDemo {
    public static void main(String[] args) {
        DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd");

        LocalDate startDate = LocalDate.parse("2026-09-03", formatter);
        LocalDate expireDate = CardDuration.ONE_MONTH.expireDateFrom(startDate);
        LocalDate today = LocalDate.of(2026, 9, 20);

        System.out.println("开卡日: " + startDate.format(formatter));
        System.out.println("到期日: " + expireDate.format(formatter));
        System.out.println("是否已过期: " + expireDate.isBefore(today));
        System.out.println("当月第一天: " + startDate.withDayOfMonth(1));
    }
}
```

这段代码把枚举和日期 API 合在一起：枚举负责有效期规则，`LocalDate` 负责具体日期，`Period` 负责日期跨度，`DateTimeFormatter` 负责输入输出格式。

## Common Misconceptions

第一个误区：`plusMonths(1)` 等于加 30 天。不是。它是日历意义上的加一个月。比如 9 月 3 日加一个月是 10 月 3 日，不是简单加 30 天。

第二个误区：到期判断只有一种写法。实际上要看业务规则：到期日当天是否还有效？如果当天有效，用 `!expireDate.isBefore(today)`；如果当天已经过期，用 `!expireDate.isAfter(today)`。

第三个误区：`Period.between()` 得到的是总天数。不是，它得到的是“几年几月几日”的拆分。如果要精确总天数，应该看 `ChronoUnit.DAYS.between(start, end)`。

第四个误区：`LocalDateTime` 比 `LocalDate` 更高级，所以总该优先用。不是。类型越精确，业务含义越复杂。只需要日期，就用 `LocalDate`。

## Socratic Check

如果会员卡的到期日是 `2026-10-03`，今天也是 `2026-10-03`，你觉得这个会员当天还算有效吗？这个业务选择会影响你用 `isBefore` 还是 `isAfter`。

再想一个细节：`Period.ofMonths(1)` 和 `Duration.ofDays(30)` 都像是“一个月左右”，但为什么会员月卡更适合用 `Period.ofMonths(1)`？

## Socratic Check Feedback

你的回答：

1. 到期日当天应该算有效，应该使用 `isAfter`。
2. 因为不同月份的天数不一样。对用户来说，几月几号开通会员，就应该在下个月的几号过期。

反馈：业务判断是对的，到期日当天算有效是很常见的会员规则。不过比较方法要稍微校正：如果今天和到期日相同，`expireDate.isAfter(today)` 会返回 `false`，因为“同一天”并不是“在今天之后”。所以当天有效时，更合适的写法是：

```java
boolean active = !expireDate.isBefore(today);
```

它的意思是：只要到期日不是在今天之前，就还有效。换句话说，到期日是今天或未来都有效。

第二题回答很好。月卡不是“30 天卡”，而是日历意义上的“下个月同一天”。这正是 `Period.ofMonths(1)` 比 `Duration.ofDays(30)` 更贴近业务的地方。否则 1 月、2 月、闰年这些日期规则会像排队买奶茶时突然插队的人一样，让逻辑变得很别扭。

## Quick Summary

- 创建日期常用 `now()`、`of()`、`parse()`。
- 日期加减常用 `plusXxx()`、`minusXxx()`、`plus(Period)`。
- 替换日期某部分用 `withXxx()`。
- 日期比较用 `isBefore()`、`isAfter()`、`isEqual()`。
- 业务周期多用 `Period`，精确耗时多用 `Duration`。
- 格式化和解析用 `DateTimeFormatter`。
