## 定位：你在知识地图的什么位置？

你已经通关了 `语言基础` 和 `面向对象编程` 两大模块——现在你能定义类、创建对象、用多态和内部类组织代码。

但到目前为止，你写的程序都在"裸奔"：

- 处理字符串还得自己 `for` 循环一个个字符数
- 判断两个对象是否相等还得自己写 `if (a == b)`
- 想要今天的日期，还得自己算
- 方法返回空值 `null`，还得自己小心翼翼判断

这些"日常琐事"，Java 官方早就帮你写好了现成的工具——这就是 **常用核心 API（Application Programming Interface，应用程序编程接口）**。

> API = 别人写好的、你可以直接调用的方法集合。就像你不需要自己造螺丝刀，直接去五金店买就行。

```
你已走过的路 ─────────── 你在这里 ─────── 前方的路
语言基础 → 面向对象编程 → ★常用核心 API★ → 集合 → 异常 → 泛型 → ...
```

**没有核心 API，你写的每一行代码都要从零开始；有了它，你站在巨人的肩膀上。**

## 核心机制：本模块的 5 个子主题

`常用核心 API` 模块下有 5 个知识点，按"日常使用频率"和"学习依赖顺序"排列：

### 1. Object、String 与包装类 ⭐（第一优先级）

这是**整个 Java 类体系的根**，你之前用的所有类都悄悄继承自 `Object`。

```java
// Object 是所有类的父类——你写的每个类都有这几个方法
public class Object {
    public boolean equals(Object obj)    // 判断"内容相等"（默认是地址相等）
    public int hashCode()                // 计算哈希值
    public String toString()             // 返回字符串表示
}

// String 是最常用的类，注意它不可变
String s = "hello";
String t = s.toUpperCase();  // 返回新字符串，s 本身不变！
System.out.println(s);        // 还是 "hello"

// 包装类：int → Integer, double → Double
// 解决"基本类型不能放进集合"的问题
Integer num = 42;             // 自动装箱
int n = num;                  // 自动拆箱
```

**为什么重要**：`equals()` vs `==` 的区别是面试必考；`String` 不可变是最常见的坑。

### 2. 日期与时间 API

Java 8 引入了全新的 `java.time` 包，彻底取代了老旧的 `Date` 和 `Calendar`。

```java
import java.time.*;

LocalDate today = LocalDate.now();          // 2026-07-15
LocalDateTime now = LocalDateTime.now();    // 2026-07-15T15:30:00
LocalDate birthday = LocalDate.of(2000, 1, 1);
Period age = Period.between(birthday, today);  // 计算年龄
```

**为什么重要**：处理日期是几乎所有业务系统的刚需（订单、日志、生日、到期日）。

### 3. 枚举（enum）

当一个变量只能取**有限几个固定值**时，用枚举代替"魔法数字/魔法字符串"。

```java
enum Day {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}

Day today = Day.FRIDAY;
if (today == Day.SATURDAY || today == Day.SUNDAY) {
    System.out.println("周末！");
}
```

**为什么重要**：类型安全——编译器会帮你检查，防止把非法值传进去。你之前在流程控制里用 `char` 表示等级（A/B/C/D/F），其实用枚举更合适。

### 4. 正则表达式（Regex）

用"模式"来匹配、查找、替换文本。

```java
import java.util.regex.*;

// 匹配手机号：1 开头 + 10 位数字
Pattern p = Pattern.compile("^1\\d{10}$");
Matcher m = p.matcher("13812345678");
boolean isValid = m.matches();  // true
```

**为什么重要**：验证用户输入（邮箱、手机号、身份证）、提取文本、日志分析——无处不在。

### 5. Optional

优雅处理"可能为 null"的值，避免 `NullPointerException`。

```java
import java.util.Optional;

Optional<String> name = Optional.ofNullable(getName());
String result = name.orElse("未知");           // 为空时给默认值
name.ifPresent(n -> System.out.println(n));    // 有值才执行
```

**为什么重要**：这是 Java 8 引入的"防空指针"神器，现代 Java 代码几乎必备。

## 常见误区（提前避坑）

**误区一："`==` 和 `equals()` 一样"** → 大错特错。`==` 比较的是**引用地址**（是不是同一个对象），`equals()` 比较的是**内容**（值相不相等）。

```java
String a = new String("hello");
String b = new String("hello");
System.out.println(a == b);       // false（两个不同对象）
System.out.println(a.equals(b));  // true（内容相同）
```

**误区二："String 可以修改"** → String 是**不可变**的，任何"修改"操作都返回新字符串。

```java
String s = "hello";
s.replace('h', 'H');   // 这行没用！返回值被丢弃
// 必须：
s = s.replace('h', 'H');  // 重新赋值才生效
```

**误区三："枚举只是常量集合"** → 枚举其实是**特殊的类**，可以有字段、构造器、方法。

```java
enum Color {
    RED("#FF0000"), GREEN("#00FF00");  // 可以有构造器！
    private final String hex;
    Color(String hex) { this.hex = hex; }
    public String getHex() { return hex; }
}
```

**误区四："正则表达式随便写写就行"** → 正则里的 `\d`、`.`、`*` 等都有特殊含义，忘记转义会匹配出意料之外的结果。

## 一句话总结

- **Object**：所有类的祖先，`equals`/`hashCode`/`toString` 是三大基本方法
- **String**：不可变的最常用类，`==` 和 `equals` 别搞混
- **包装类**：基本类型的"对象外衣"，解决集合和泛型的需要
- **日期时间**：`java.time` 包（LocalDate/LocalDateTime），告别老 Date
- **枚举**：类型安全的常量集合，本质是特殊类
- **正则**：文本匹配与验证的利器
- **Optional**：防空指针的优雅方案

> 💡 核心 API 让你从"什么都自己做"进化到"站在巨人的肩膀上"。学会它们，你的编码效率和代码质量会有一个质的飞跃。
