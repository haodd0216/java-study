enum CardType {
    ONE_YEAR("一年卡", 1),
    THREE_YEARS("三年卡", 3),
    LIFETIME("终身卡", -1);

    private final String text;
    private final int years;

    CardType(String text, int years) {
        this.text = text;
        this.years = years;
    }

    String getText() {
        return this.text;
    }

    int getYears() {
        return this.years;
    }

    boolean isLifetime() {
        return this == LIFETIME;
    }

    static CardType fromText(String text) {
        CardType value = null;
        for (CardType cardType : CardType.values()) {
            if (cardType.text.equals(text)) value = cardType;
        }
        if (value == null) {
            throw new IllegalArgumentException("错误的枚举值");
        };
        return value;
    }
}

```java
static CardType fromText(String text) {
    String trimmed = text.trim();
    for (CardType cardType : CardType.values()) {
        if (cardType.text.equals(trimmed)) {
            return cardType;
        }
    }
    throw new IllegalArgumentException("未知会员卡类型: " + trimmed);
}
```

这个版本还有一个好处：找到结果就立刻 `return`，不需要先定义 `value = null` 再循环结束后判断，逻辑更直接。
