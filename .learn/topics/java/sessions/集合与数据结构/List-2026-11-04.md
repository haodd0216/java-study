**`List` 是 Java 中表示有序元素序列的集合接口，支持按从 0 开始的索引访问元素。**

> 日期：2026-11-04  
> 主题：Java  
> 知识位置：集合与数据结构 → List  
> 讲解层级：入门，衔接已学过的数组、接口和多态。

你学过的数组创建后长度固定。管理人数不断变化的学生名单时，使用 `ArrayList` 可以直接增删元素，由它管理底层数组的容量。

先区分两个名字：**`List` 定义操作规则，`ArrayList` 是实现这些规则的具体类。** `List` 还有其他实现，因此不能把所有 `List` 都当成可变长度数组。

理解 `List`，先掌握这些规则：

- **有序**表示元素有明确的位置，遍历遵循当前的位置顺序；元素不会因为放进列表就自动按大小排序。
- **通常允许重复元素**。本节使用的 `ArrayList` 允许重复元素，也允许 `null`；其他列表对元素的限制可能不同。
- `size()` 返回当前元素数量。`get(i)` 读取、`set(i, value)` 替换、`remove(i)` 按索引删除时，都要求 `0 <= i < size()`。
- `add(i, value)` 在指定位置插入，允许 `0 <= i <= size()`；取 `size()` 就是在末尾添加。以上索引越界时，会抛出 `IndexOutOfBoundsException`。
- **能否增删、替换，取决于具体列表。** 不支持的修改操作可能抛出 `UnsupportedOperationException`。下面的 `new ArrayList<>()` 支持这些操作。

可以把它想成一张按位置排列的学生名单：同名学生可以出现多次，在中间插入一项后，后面的项顺次后移。这个比喻帮助理解顺序和重复；Java 的索引从 0 开始，而且名单是否允许修改仍由具体列表决定。

下面是一个可以直接运行的完整示例：

```java
import java.util.ArrayList;
import java.util.List;

public class ListDemo {
    public static void main(String[] args) {
        List<String> names = new ArrayList<>();

        names.add("小明");
        names.add("小红");
        names.add("小明"); // 允许重复

        names.add(1, "小李"); // 插入，后面的元素后移
        names.set(2, "小王"); // 替换，元素数量不变
        names.remove(0);     // 按索引删除
        names.remove("小明"); // 按内容删除第一个匹配项

        System.out.println(names);        // [小李, 小王]
        System.out.println(names.get(0)); // 小李
        System.out.println(names.size()); // 2

        for (String name : names) {
            System.out.println(name); // 依次输出小李、小王
        }
    }
}
```

创建列表的这一行，正好用到了你学过的多态：

`List<String> names = new ArrayList<>();`

- 左边的 `List` 是接口类型，右边创建的是 `ArrayList` 对象。
- `<String>` 是泛型写法，限制通过这个变量添加的元素为 `String` 类型；右边的 `<>` 让编译器推断类型。
- 泛型参数要使用引用类型。保存整数写 `List<Integer>`，添加 `1` 时会自动装箱。

跟着示例观察名单变化，重点比较 **插入 `add`** 和 **替换 `set`**：

| 执行到哪一步 | 当前列表 | `size()` |
|---|---|---|
| 三次末尾添加 | `[小明, 小红, 小明]` | 3 |
| `add(1, "小李")` | `[小明, 小李, 小红, 小明]` | 4 |
| `set(2, "小王")` | `[小明, 小李, 小王, 小明]` | 4 |
| `remove(0)` | `[小李, 小王, 小明]` | 3 |
| `remove("小明")` | `[小李, 小王]` | 2 |

`set` 返回被替换的旧元素，`remove(int)` 返回被删除的元素；`remove(Object)` 则返回是否成功删除的布尔值。

还需要留意几个常见误区：

**同样声明成 `List`，修改能力也可能不同。**

| 创建方式 | 添加、删除 | 替换 `set` | 允许 `null` 元素 |
|---|---|---|---|
| `new ArrayList<>()` | 支持 | 支持 | 允许 |
| `Arrays.asList("甲", "乙")` | 不支持，长度固定 | 支持 | 允许 |
| `List.of("甲", "乙")`，Java 9+ | 不支持 | 不支持 | 不允许 |

`Arrays.asList` 返回的列表与原数组共享元素存储。`List.of` 限制的是列表的增删和替换，并不保证元素对象自身不可变。

**存整数时，要分清两种 `remove`。** 对于 `List<Integer> numbers`，`numbers.remove(1)` 删除索引为 1 的元素；`numbers.remove(Integer.valueOf(1))` 删除第一个值等于 1 的元素，找不到则返回 `false`。

**按内容查找、删除与 `equals()` 有关。** `contains`、`indexOf`、`remove(Object)` 按相等规则匹配元素，并处理 `null` 的情况；自定义对象如何算相等，取决于它的 `equals()` 实现。

**增强 `for` 内直接增删列表可能出错。** 遍历 `ArrayList` 时，在增强 `for` 内直接调用列表的 `add`、`remove`，可能抛出 `ConcurrentModificationException`。安全删除可以随后学习迭代器或 `removeIf`。

可以先想一想这两个小问题，两题都从 `[小明, 小红]` 开始：

1. 执行 `names.add(1, "小李")` 后，`names.get(2)` 会得到谁？
2. 如果改为执行 `names.set(1, "小李")`，列表内容和元素数量会怎样变化？

提示：插入会让原位置及其后面的元素后移；替换只改变原位置的内容。

本节的三个要点：

- `List` 定义有序序列的操作，`ArrayList` 提供可变长度的数组实现。
- 索引从 0 开始，`add` 插入、`set` 替换、`remove` 删除，作用不同。
- 使用列表时，同时留意具体实现的修改限制和方法参数的类型。
